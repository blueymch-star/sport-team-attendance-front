# 國小運動代表隊 · 線上現場秒點名前台 (Sport Team Attendance Front)

專為學校運動代表隊（田徑隊、排球隊）操場與球館現場考勤設計的極簡 Mobile-first 秒點名系統。

## 🌟 特點
- 📱 **Mobile-First 現場體驗**：大字體、大按鍵觸控操作，手機瀏覽器即開即點。
- 🏃 **田徑 / 排球雙校隊切換**：快速切換代表隊名單。
- ☀️ **雙時段考勤支援**：晨操 (`08:00~08:40`) 與午訓 (`12:40~13:20`) 雙時段切換。
- ⚡ **快速批次點名**：「一鍵全員出席」與「標記今日無訓練」。
- ☁️ **Google Apps Script 雲端同步**：支援與 Google 試算表雙向同步，本機行政後台可一鍵拉取最新點名結果。
- 🛡️ **資安去識別化**：僅包含隊員姓名、班級與出勤紀錄，無任何身分證號、電話或學校內部行政機密資料。
